# Retail Sales Analysis Using Excel

## Project Overview
This project analyses retail sales transaction data using Microsoft Excel, Power Query, PivotTables, PivotCharts, and interactive slicers.

## Tasks Completed
- Combined multiple CSV files using Power Query.
- Cleaned data and assigned appropriate data types.
- Created calculated columns for total cost, expected revenue, profit, and profit margin.
- Created PivotTables for regional, product, and quarterly analysis.
- Calculated regional profit margins and quarterly revenue growth.
- Developed PivotCharts for business performance analysis.
- Added interactive slicers for dynamic filtering.
- Applied conditional formatting to KPI metrics.
- Created a retail sales dashboard with key performance indicators.

## Tools and Technologies
Microsoft Excel, Power Query, PivotTables, PivotCharts, Slicers, Conditional Formatting.

## Calculation Assumption
Expected Revenue is calculated as Unit Price × Quantity Sold × (1 − Discount). This is an analytical assumption based on the available dataset fields. The business definition of the original Sales_Amount field was not confirmed.
