# SQL Fundamentals — Week 1, Day 1

## Project Overview
This project demonstrates fundamental SQL skills using a sample sales database created in MySQL Workbench.

## Objectives
- Retrieve data using SELECT statements.
- Filter records using WHERE conditions.
- Apply AND, OR, and NOT operators.
- Use LIKE, IN, BETWEEN, and IS NULL.
- Calculate revenue using quantity and unit price.
- Sort query results using ORDER BY.
- Export query results to CSV.

## Database Details
- **Database:** `sales_db`
- **Table:** `sales`
- **Records:** 12 sample sales records
- **Tool:** MySQL Workbench

## Deliverables
- `sales_queries.sql` — SQL script containing the database setup, sample data, and practice queries.
- `sales_report.csv` — exported sales query results.

## How to Run
1. Open MySQL Workbench and connect to your MySQL server.
2. Execute the SQL script to create and populate the sales table.
3. Run the SELECT queries individually to inspect the results.
4. Export a query result to CSV.

## Key Learning Outcomes
Practiced SQL data retrieval, filtering, logical operators, pattern matching, range conditions, NULL handling, calculated columns, and sorting.
