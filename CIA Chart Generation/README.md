
# CIA Chart Generation

Interactive Data Visualization Dashboard using Plotly and Apache ECharts.

## Features

- Interactive monthly sales bar chart using Plotly.
- Product category doughnut chart using Apache ECharts.
- KPI cards for sales, orders and customers.
- Responsive dashboard layout.
- Interactive chart tooltips and controls.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Vite
- Plotly.js
- Apache ECharts
- Node.js

## Installation

Install dependencies:

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
